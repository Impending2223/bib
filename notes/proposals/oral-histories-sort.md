# The JFK and RFK oral histories, sorted into the reading plan's batches

This note sorts the 840 transcripts of batch O1 by subject. The table is in `notes/proposals/oral-histories-sort.tsv`. It has one row for each transcript, with a chief batch, any other batches the scope names, and a few words on why.

The sort uses only the finding aids' one-sentence scopes and who the interviewee was. No transcript was opened. Where a scope is general, the interviewee's job decided the batch. Where a scope names no subject of any batch, the transcript stays in O1.

Three of the 840 files are not interviews. They are saved web pages of the libraries' collection pages: the John F. Kennedy collection page (52 pages) and the Robert F. Kennedy collection page, saved once in each library's folder (13 pages each). They are marked `page` and are in no batch. The brief said two; there are three. That leaves 837 interviews and 29,702 pages.

The 46 rows with no code were matched by the interviewee's name and the interview's number. 43 were matched to a code and a scope. Three were the web pages. Four of the 43 need a check, and are listed below.

## Stays in O1

43 interviews, 1,455 pages, stay in O1. Their scopes are about the Kennedys' persons, families and friendships and name no subject of a batch. Examples are the interviews on JFK's health, the White House renovation, the Hemingways, the Mount Kennedy climb, Art Buchwald, and Jacqueline Kennedy's own interview.

## More than one subject

675 of the 837 interviews have a scope that names the subject of a second batch or more. Their `also` column lists those batches. O1 is never listed as an `also`. The batches named most often as a second subject are U9 (145), U8 (100), U1 (96), U4 (60), F1 (59), U3 (50), H1 (48) and W4 (44). U9 is high because many 1960 and 1964 campaign scopes name a State or a city.

Some `also` lists are short. A scope that I read in full gave all its subjects. A few long scopes name many places and I listed the main ones.

## Rows I was least sure of

Four matches of a file to a finding-aid code need a check, because the file's own name does not agree with the code left over.

- Blair, file `#1` (23 pages): coded `JFKOH-WMB-02`. The other Blair row already holds WMB-01.
- Wilson, file `JFKOH-DMW-01-TR` (24 pages): coded `JFKOH-DMW-02`. The other Wilson row already holds DMW-01.
- Russell, file `JFK1` (30 pages): coded `JFKOH-FHR-02`. The other Russell row already holds FHR-01.
- O'Donnell, file `RFKOH-KPO-02-TR` (83 pages): coded `RFKOH-KPO-02`. The row already coded KPO-02 also has 83 pages, so this is probably a second copy of the same transcript.

In the first three, the file name and the code taken from the finding aid disagree about the interview number. I took the code that is not yet used. If the files are in fact duplicates of the coded rows, they should be dropped from O1.

Ten rows have no scope in the finding aid, or a scope cut short. I sorted them by the interviewee's job: Kohler (F1), Donahue 3 and 4 (U1), Gilpatric (D1), Vanocur JFK 2 and 3 and Wilson JFK 2 (P1), Wilson RFK 2 (U8), and Rafer Johnson RFK 1 and 2 (U8). The Johnson rows are the weakest, because I know him only as a friend and a worker in the 1968 campaign.

Two groups were close calls between batches. The Justice Department interviews on organized crime, wiretaps and Hoover went to U5, and the ones on staff, appointments and reform went to U1. The State Department and ambassador interviews with no one region went to F1, though F1 is a batch of documents and the interviews could as well go to U1.
