# Drea, *McNamara, Clifford, and the Burdens of Vietnam* (2011): the calendar reread (stage 3)

Edward J. Drea, *McNamara, Clifford, and the Burdens of Vietnam, 1965–1969* (Secretaries of Defense Historical Series, vol. VI, 2011), card `w.drea-mcnamara-clifford-and-the-2011`. Read Oct. 28–29, 2026, from archive.org's DTIC scan (`DTIC_ADA552481`; the OSD Historical Office's PDF on history.defense.gov refused this environment, 403), each page's number from its running head: text pages are leaves 18–233 (folio = leaf − 17), 246–469 (leaf − 29) and 486 on (leaf − 45), with plates between. archive.org's page labels go wrong after the plates: it labels the leaf of page 441 "457", which is where the Oct. 23 run's "457" for the hot line came from. Endnotes by chapter, pp. 555–653; the OCR garbles some note numbers, so each note was matched to its passage by content.

Every pinpoint to this volume in the calendar (91 entries) was read against the entry's units (`./bib claims show ID`), the page sentence by sentence. The patch `inbox/2026-10-29-histories-osd-b.yaml` (patch `histories-osd-b`) writes each entry's claim map (`src`): this volume's rows by page and units, a parenthetical in the note where the page bears out only some of the entry, and a `via` row for each record the page's note gives for those units (described in `sources/cited-records/drea-mcnamara-clifford-and-the-2011.yaml`). Where FRUS prints a record the note cites, it was read; where it bears the entry out it is cited in the note before Drea, and where it is not read or not found, it joins the note's "To check:" with Drea's page and note. Secondary works in Drea's notes are not logged as records. A record a note gives for a passage is tied to the units the passage covers; several records under one note take the same letters.

Entries mapped: 90 (cal.1967-09-07.vietnam left: Drea does not treat the announcement). Pinpoints moved, narrowed or widened: 18. Parentheticals written: 83. Checks added: 5. Records logged: 151 (123 found in FRUS or the Public Papers and read; 28 not found in print). New entries: 11.
