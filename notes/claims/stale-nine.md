# The nine stale maps, read again (Nov. 26, 2026)

The patch is `inbox/2026-11-26-stale-nine.yaml`. For each entry it has one `edit` that sets the map's line hash to the present line (the hash is also quoted where it was a bare number, which YAML read as an integer and so showed as stale) and drops the rows that named letters, then one `src` op for each source and part, naming the part by its words (`on:`) or a field (`on: date`, `place`). No word of any line is changed. A `src` op cannot run on a stale map, which is why the `edit` comes first; patch-check shows 0 errors, and the patch applied in memory leaves all nine maps fresh. Every page below was read in the copy on the Drive (scan pages on the image, text layers and the epubs as text). A source that bears out only part of a unit is mapped to the whole unit, because a part is a run of whole units.
